# Bank Management System

## Overview

The Bank Management System is a Java-based application developed using Object-Oriented Programming (OOP) concepts. The project simulates basic banking operations and provides a simple interface for managing customer accounts and transactions.

## Features

* Create New Bank Accounts
* Deposit Money
* Withdraw Money
* Check Account Balance
* View Customer Information
* Account Management
* Transaction Processing
* Input Validation and Error Handling

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* NetBeans IDE
* Java Collections Framework

## OOP Concepts Implemented

* Classes and Objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Constructors
* Method Overloading and Overriding
* Exception Handling

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/hackhathon-BANK-management-system.git
```

2. Open the project in NetBeans, IntelliJ IDEA, or Eclipse.

3. Compile and run the `Main.java` file.
